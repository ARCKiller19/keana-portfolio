# Keana Portfolio

A portfolio site for Patricia Keana Roma, built as an editorial, botanical-tech experience with sections for selected work, motion/video, playground studies, and contact.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

## Notes

- Main site content lives in `src/`.
- Public images and media live in `public/`.
- The site is deployed through Vercel from the `main` branch.
